Welcome to Ribbon

A scrolling window manager for your Mac. Every window is a column on one long strip that runs past the edges of the screen, so opening a window never squeezes the others.

Install in three steps

Drag Ribbon into Applications

In the window this guide came from, drag the Ribbon icon onto the Applications folder. Then eject the “Ribbon” disk.

Open it the first time

Open Applications and double-click Ribbon. This is a private build that isn't notarised by Apple, so the first time macOS shows a warning that it “could not verify” Ribbon. That's expected. Click Done, then:

1. Open System Settings → Privacy & Security.
2. Scroll down to the line “Ribbon was blocked…” and click Open Anyway.
3. Enter your password and click Open Anyway again.

You only do this once. Prefer Terminal? This one line does the same:

xattr -dr com.apple.quarantine /Applications/Ribbon.app && open /Applications/Ribbon.app

Follow the welcome tour

Ribbon opens a short tour. It asks for Accessibility access (that's how any window manager moves windows), checks your Mac's settings, and lets you practise the five shortcuts you'll use most. It takes about two minutes.

Updating later? After replacing Ribbon with a newer copy, macOS may keep an old Accessibility entry that no longer works. Open Privacy & Security → Accessibility, select Ribbon, click –, then open Ribbon again and allow it.

The five shortcuts to learn first

Focus the next window (the strip scrolls to show it)⌃⌥→ ⌃⌥←
Move the focused window along the strip⌃⌥⇧→ ⌃⌥⇧←
Cycle preset widths (¼, ⅓, ½, ⅔, ¾)⌃⌥R
Stack a window under its left neighbour⌃⌥[
Show every shortcut⌃⌥/

⌃ is Control, ⌥ is Option, ⇧ is Shift, ⌘ is Command. Every shortcut can be changed in Settings → Shortcuts.

Mouse and trackpad

Swipe

Slide three fingers left or right and the strip follows, then settles on the nearest window. You can switch to four fingers in Settings.

Scroll wheel

Hold ⌃⌥ and scroll to move the strip with a mouse.

Drag to reorder

Drag a window by its title bar and drop it between two others. Drop it on another display to move it there.

Resize

Drag a window's edge as usual; Ribbon remembers the new width for that column.

Strip map

Hold ⌃⌥: a map of the strip appears. Click a tile to jump to it, drag tiles to reorder.

Menu bar

The three-column icon in the menu bar has Pause, Settings, Mac Setup, the window list and the tour.

If something isn't right

  • Nothing moves. Check System Settings → Privacy & Security → Accessibility has Ribbon switched on. If it already is, remove it with – and add it again.
  • Windows jump back after you move them. Another window manager (Rectangle, Magnet, Moom, Amethyst…) is running, or macOS edge tiling is on. Ribbon's Mac Setup page finds both.
  • A swipe changes desktops instead. macOS uses the same number of fingers. In System Settings → Trackpad → More Gestures, set “Swipe between full-screen applications” to four fingers (or off), or switch Ribbon to four fingers.
  • A shortcut does nothing. Another app may own it; Settings → Shortcuts shows taken shortcuts in orange and lets you pick another.
  • Windows are stuck at the screen edge after quitting. Ribbon brings them back when it pauses or quits. If it ever crashes, open it again and press ⌃⌥Q twice.

Extras

  • URL scheme: every command is a link, e.g. open -g "ribbon://focus-right". Use it from Shortcuts, Keyboard Maestro or a Stream Deck.
  • Command-line tool: Settings → Automation → Install. Then ribbon help, ribbon state, ribbon config set innerGap 6.
  • Raycast: Settings → Automation → Export Raycast Commands, then add the folder in Raycast.
  • Privacy: no account, no telemetry, no network. Ribbon only moves windows and never reads what's on screen.

Uninstall

Quit Ribbon from its menu bar icon, drag it from Applications to the Bin, and remove it from Privacy & Security → Accessibility. Settings live in ~/Library/Preferences/in.thegent.ribbon.plist and layouts in ~/Library/Application Support/Ribbon.

Ribbon 1.0 · requires macOS 13 Ventura or later · runs natively on Apple silicon and Intel Macs.
