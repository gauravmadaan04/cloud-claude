Welcome to Ribbon

Windows that arrange themselves. Open a window and it takes its place; close one and the others fill the space. Everything else is one click away in the menu bar: no shortcuts to learn.

Install in three steps

Drag Ribbon into Applications

In the window this guide came from, drag the Ribbon icon onto the Applications folder. If an older Ribbon is there, choose Replace. Then eject the “Ribbon” disk.

Open it the first time

Open Applications and double-click Ribbon. This is a private build that isn't notarised by Apple, so the first time macOS shows a warning that it “could not verify” Ribbon. That's expected. Click Done, then:

1. Open System Settings → Privacy & Security.
2. Scroll down to the line “Ribbon was blocked…” and click Open Anyway.
3. Enter your password and click Open Anyway again.

You only do this once. Prefer Terminal? This one line does the same:

xattr -dr com.apple.quarantine /Applications/Ribbon.app && open /Applications/Ribbon.app

Take the two-minute tour

Ribbon asks for Accessibility access (that's how any window manager moves windows), shows the basics, lets you pick grid or columns, and ends with Tidy My Workspace: your windows fall into place.

Updating from an older Ribbon? Ribbon clears the old Accessibility entry by itself on first launch; just switch Ribbon on again when macOS asks. If it ever keeps asking, use Fix permission in the Ribbon menu.

How it works

The menu bar

Click the Ribbon icon at the top right. Click a layout picture to rearrange the screen, click a window in the map to switch to it, drag one onto another to swap. ⌃⌥Space opens it from the keyboard.

Automatic

Each screen holds 1 to 4 windows (3 to start). The first window is the main one on the left; the others share the right. New windows take their place as they open.

Stacks

When a screen is full, a new window sits on top of the one you're using. ⌃⌥` or the grip above it switches between them.

Grid, columns or scrolling

Pick per screen in the menu bar. Scrolling puts windows side by side on a strip that runs past the screen edges; swipe with three fingers or hold ⌃⌥ and scroll.

Mouse

⌘-drag a title bar onto another window to swap them; ⌥⌘-drag to stack. Drag the edge between two windows to resize both.

Prefer the keyboard?

You never need a shortcut, but they're all there. The one worth remembering is ⌃⌥Space: it opens the panel, where single keys work (1–4 windows, G C S for grid, columns, scrolling, arrows to swap, ↩ for the main window).

If something isn't right

  • Ribbon keeps asking for Accessibility, but it's already switched on. macOS is holding an entry from an older copy of Ribbon. Click Fix permission (in the Ribbon menu, the tour or Settings → General), then switch Ribbon on once more. Still asking? Click Relaunch.
  • Windows jump back after you move them. Another window manager (Rectangle, Magnet, Moom, Amethyst…) may be running. Quit it, or turn off its automatic arranging.
  • Ribbon says it's paused. Stage Manager is on; Ribbon steps aside until you turn it off (or untick that in Settings → General).
  • A shortcut does nothing. Another app may own it. The menu bar panel warns you, and Settings → Shortcuts shows taken keys in orange.
  • A three-finger swipe changes desktops too. In Settings → Layout, switch the scrolling swipe to four fingers.
  • An app looks wrong tiled. Click the menu bar icon while that app is in front and switch off “Tile <app>”.

Extras

  • URL scheme: every command is a link, e.g. open -g "ribbon://swap-right". Use it from Shortcuts, Keyboard Maestro or a Stream Deck.
  • Command-line tool: Settings → Advanced → Install. Then ribbon help, ribbon state, ribbon config set spacing 12.
  • Raycast: Settings → Advanced → Export, then add the folder in Raycast.
  • Privacy: no account, no analytics, no network. Ribbon only moves windows and never reads what's in them.

Uninstall

Quit Ribbon from its menu bar panel, drag it from Applications to the Bin, and remove it from Privacy & Security → Accessibility. Settings live in ~/Library/Preferences/in.thegent.ribbon.plist and layouts in ~/Library/Application Support/Ribbon.

Ribbon 2.0 · requires macOS 13 Ventura or later · runs natively on Apple silicon and Intel Macs.
