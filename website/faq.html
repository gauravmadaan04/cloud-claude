Getting started

What is Haven?

Haven is a Mac app for finding, cleaning up and working on your files. It searches in plain English and reads the text inside images and documents, finds duplicates and clutter, and puts 27 tools for images, PDFs, video, audio and on-device AI one right-click away.

Does Haven replace Finder?

No, it works alongside Finder. Your files stay in the folders they're already in. Haven indexes them so you can find them, clean up and work on them faster, and any file is one shortcut away from Finder.

Which folders does Haven look at?

The ones you pick when you first open it, usually Desktop, Documents and Downloads, plus any you add later in Settings. macOS asks for your permission before Haven can read each one.

Which Macs does it run on?

Any Mac with macOS 14 Sonoma or later, with Apple silicon or Intel. Translate needs macOS 15 or later, and Summarize needs a Mac with Apple Intelligence on macOS 26.

How much space does Haven use?

Very little. Its search index for a library of 300,000 files is about 18 MB. If you use Transcribe, the Whisper speech model takes 190 MB, or 574 MB for the Best Quality model.

Features

How does plain-English search work?

Type what you remember, like “screenshots over 5 MB” or “photos from whatsapp last month”. Haven picks out the kind of file, the dates, sizes, sources and folders, and shows each one as a chip. Remove a chip to widen the search. Anything left over is matched against file names and the text inside files.

Can Haven really read the text in my screenshots?

Yes. Haven uses Apple's on-device text recognition to read screenshots, photos and scanned PDFs in the background, newest first. The first pass takes a little while after you install Haven; after that, new files are read as they arrive.

How does transcription work?

Haven runs Whisper, an open-source speech recognition model, on your Mac. The first time you transcribe, you choose Faster (190 MB) or Best Quality (574 MB, recommended on Apple silicon), and Haven downloads it once. It can detect the language or you can pick one of 20+, and it can translate the speech into English. You get a text file, subtitles (.srt), or both.

Do the file tools change my originals?

Never. Every tool makes a new file next to the original, with a clear name like “Team call (720p).mp4” or “Lease agreement (signed).pdf”. Undo moves what a tool made to the Trash.

What is Dialog Jump?

When an Open or Save dialog is on screen in any app, Haven can send it to the folder you're looking at in Haven, so you don't click through folders again. It needs Accessibility permission, because it types the folder's path into the dialog for you.

Does it work with iCloud Drive?

Yes, add your iCloud Drive folders like any others. Files that are only in iCloud and not downloaded to this Mac are skipped when Haven looks for duplicates.

Privacy and safety

Are my files uploaded anywhere?

No. Search, text recognition, transcription, background removal and every file tool run on your Mac. Haven goes online only to download a speech model if you ask for transcription, check for updates and activate your license. Privacy policy

Does Haven collect analytics?

No. The app has no analytics, tracking or ads, and no account.

Could Haven delete something I need?

Haven never deletes anything outright. Clean Up and Duplicates always show you the files first. When you confirm, they go to the Trash, and Undo or the Activity page puts them back. Rules are off until you turn them on, and they never touch files inside your project folders.

What permissions does Haven ask for?

Access to the folders you choose. If you use Dialog Jump, it also asks for Accessibility. Nothing else.

Troubleshooting

Haven doesn't find the text in an image.

Text reading happens in the background, newest files first, so give it a few minutes after you first install Haven. Very small, blurry or handwritten text may not be read.

A folder is missing from Haven.

Open Settings › Folders and check that it's listed. If macOS asked for permission and you said no, allow it in System Settings › Privacy & Security › Files and Folders.

How do I uninstall Haven?

Quit Haven and drag it from Applications to the Trash. To remove its index, settings and speech models too, delete the Haven folder in ~/Library/Application Support.
